# Brand source art

Full-size originals from the design phase. Not deployed — the site uses the trimmed PNGs in
[frontend/src/assets/](../frontend/src/assets/), which were cut from these.

- `logo-master.png` — primary logo lockup
- `brand-sprite.png` — logo variants, icons, textures and the color palette
- `favicon-source.png` — the green sun badge cut from `brand-sprite.png` (134px, transparent
  corners). The site icons in [frontend/public/](../frontend/public/) were made from it:
  - `favicon.ico` — 48px full badge; 32px and 16px zoomed in on the sun and leaf so they read at
    tab size
  - `apple-touch-icon.png` — 180px badge on the cream site background (iOS rounds the corners)
